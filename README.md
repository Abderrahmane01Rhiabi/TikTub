# TikTok to YouTube Shorts Automation

## Quick Setup:
1. Install dependencies: `pip install -r requirements.txt`
2. Copy `credentials.json.example` to `credentials.json` and add your YouTube API credentials
3. Add background images (JPG/PNG) to the `backgrounds/` folder
4. Run: `python script.py`

## Next Steps:
- Get YouTube API credentials from Google Cloud Console
- Add high-quality background images (1080x1920 recommended)
- Test with one of your TikTok video URLs

## Folders:
- `backgrounds/` - Put your background images here
- `temp/` - Temporary files (auto-managed)
- `processed_videos/` - Final output videos
